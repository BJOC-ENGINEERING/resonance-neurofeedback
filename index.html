How it works. Simulated modes generate EEG-like signals from oscillators, pink noise and optional artifacts. Live Muse 2 reads the headset's four EEG electrodes at 256 hz over Web Bluetooth. Both sources use the same windowed spectrum, three-second baseline and adaptive reward loop: activity above threshold raises the tone, blooms the visual and earns points. The experimental resonance mode models 7.63, 19.99 and 32.57 hz. This is an educational trainer, not a medical device; EEG data is processed locally.
